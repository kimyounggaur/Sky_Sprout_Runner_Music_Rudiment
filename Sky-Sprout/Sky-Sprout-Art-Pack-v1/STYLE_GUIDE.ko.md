# 아트·UI 스타일 가이드

## 방향 — 햇빛을 머금은 하늘 정원

원본의 새싹 주인공과 구름 섬을 중심으로 합니다. 풍부한 색감, 입체적인 덩어리, 읽기 쉬운 실루엣, 행동에 즉시 반응하는 연출을 품질 기준으로 삼습니다. 특정 기존 게임의 캐릭터·로고·파이프·상징을 옮기지 않습니다.

광원은 좌상단의 따뜻한 햇빛입니다. 상단은 노랑이 섞인 밝은 색, 우하단은 청록색 그림자로 부피를 표현합니다. 검정 외곽선 대신 명도 차이와 짧은 접촉 그림자를 사용합니다. 세부 무늬는 실루엣과 눈을 방해하지 않도록 합니다.

## 캐릭터

새싹은 둥근 녹색 씨앗 몸, 줄기 위 두 잎, 어두운 타원형 눈, 짧은 초록 발이 핵심입니다. 새 시트에는 작은 팔을 더해 점프와 착지의 방향을 표현했습니다. 잎은 동작을 따라 지연되며 눈의 하이라이트는 한 방향을 유지합니다. 화면상 44~88px 높이를 기본으로 보고, 32px 이하에서는 표정 디테일을 줄인 별도 LOD 제작을 권장합니다.

실루엣 보존이 표면 디테일보다 우선입니다. 잎까지 포함한 시각적 크기와 충돌 영역을 분리하세요. 잎·팔·밑그림자는 물리 충돌에 포함하지 않습니다. 개별 PNG와 스트립은 256×256 프레임에 정리했고 발 기준은 프레임 y≈244입니다.

## 색의 역할

| 역할 | 기준색 | 사용 |
|---|---|---|
| 주인공 / 생명 | `#97DF4D`, `#328A54` | 주인공, 체력 잎, 안전한 표면 |
| 수집 / 주 행동 | `#FFD454`, `#E59B2B` | 빛의 씨앗, 주요 CTA, 보상 |
| 배경 / 공기 | `#76CDF5`, `#DFF8F3` | 하늘과 먼 섬 |
| UI 본문 | `#174B50` | 크림 패널 위 텍스트와 조작 아이콘 |
| UI 면 | `#FFFEF5`, `#F5E9CA` | 읽기 쉬운 HUD, 결과 카드 |
| 적 / 위협 | 산호 분홍·보라·아이보리 가시 | 수집물과 형태·색 둘 다 구별 |

색만으로 의미를 전달하지 않습니다. 체력은 잎, 씨앗은 뾰족한 물방울, 위험은 가시, 이동은 화살표입니다. PNG는 표면 조명의 변화가 있으므로 위 색은 UI와 방향을 위한 기준 토큰입니다.

## 공간과 레이어

먼 하늘 → 청록색 중경 섬 → 구름 발판 → 풀섬 / 블록 → 수집물 / 적 → 주인공 → 반응 이펙트 → HUD 순서입니다. 중경은 미리보기에서 알파 0.38로 낮춰 전경과 분리했습니다. 배경 섬의 밝은 외곽을 착지 가능한 발판으로 오해하지 않게 흐리거나 낮은 대비로 유지합니다.

풀섬의 상단 잔디 선이 착지 위치입니다. 구름 발판은 위쪽이 수평이며 하단은 둥글게 부풀어 구별됩니다. 플랫폼을 원래 비율과 다르게 길게 늘이지 마세요. 큰 섬은 비율 유지, 블록은 개별 모듈 반복으로 사용합니다. 현재 이미지는 무한 반복 가능한 seamless texture가 아닙니다.

## HUD와 화면 흐름

상단 왼쪽에는 체력과 씨앗, 오른쪽에는 점수와 일시정지를 둡니다. 체크포인트는 보조 정보입니다. 작은 화면에서는 점수를 숨기되 체력·씨앗·일시정지는 유지합니다. 본문·숫자는 이미지에 굽지 않고 DOM 또는 Phaser Text로 렌더링하세요.

시작 화면은 제목, 주인공, 한 줄 목표, 주요 시작 버튼 순서입니다. 결과 화면은 성취, 새싹의 표정, 점수/씨앗/시간, 다음 행동으로 구성합니다. 실패 화면에서는 같은 카드 컴포넌트에 ‘다시 도전’을 주요 행동으로 제공합니다. 성공 화면 예시는 정적인 디자인 수치입니다.

## 모바일

기존 화면은 390px 너비에서 Canvas가 390×219.375로 축소돼 HUD와 터치 입력이 작았습니다. 개선안은 390px 세로에서 366×480 장면을 사용하고 HUD를 CSS 픽셀로 고정합니다. 장면은 카메라 폭을 줄여 보여주므로 전체 맵의 양쪽 끝은 동시에 보이지 않습니다. 실제 통합 때는 플레이어 진행 방향을 보는 카메라 추적이 필요합니다.

터치 목표 최소 44×44px, 조작 버튼 간격 최소 6px, 주 점프 버튼 67×70px를 사용했습니다. 노치가 있는 기기에서는 safe-area-inset을 추가하세요. 가로 모드에서는 장면이 전체 높이를 사용합니다. 키보드 포커스 링을 제공하고, 모션 감소 환경에서는 반복 배경 움직임을 기본 해제합니다.

## 피드백

입력은 즉시 포즈에 반영하고 보상 숫자는 120ms 안에 갱신합니다. 수집 링은 550ms 안에 사라지고 착지 먼지는 170ms만 보여줍니다. 점프 시선·씨앗 경로를 가리는 파티클은 금지합니다. 과한 화면 흔들림, 긴 점멸, 항상 움직이는 HUD는 피합니다. 실제 게임에서는 무적 상태를 색만 바꾸기보다 짧은 테두리·투명도 변화로 함께 표현하세요.
