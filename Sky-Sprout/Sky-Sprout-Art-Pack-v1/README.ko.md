# Sky Sprout — 바람이 자라는 섬

대표 플레이 장면을 검증하는 **독립 에셋 패키지 v1**입니다. 기존 초록 새싹, 빛의 씨앗, 구름 섬의 정체성을 유지하면서 형태·색·화면 위계·피드백을 발전시켰습니다. 원본 게임을 수정하거나 커밋·푸시·배포하지 않았습니다.

## 바로 보기

1. ZIP을 풀고 `index.html`을 Chrome/Edge에서 여세요. 설치·서버·인터넷 연결 없이 작동합니다.
2. 시작 / 플레이 / 결과 화면을 전환하세요. 점프, 씨앗 수집, 일시정지와 재개를 확인할 수 있습니다.
3. `gallery.html`에서 투명 배경과 48px / 32px 축소 모습을 확인하고 개별 에셋을 내려받으세요.
4. `evidence/comparison-desktop.png`, `evidence/comparison-mobile.png`에서 기존 실제 화면과 새 미리보기를 비교하세요.

미리보기는 에셋과 UI 피드백 검증용입니다. 충돌·맵 진행·정식 게임 로직은 포함하지 않습니다. 결과 화면의 점수·시간은 디자인 예시이며, 실제 플레이 기록이 아닙니다. 세로 화면에서는 세계를 잘라 보여주고 HUD와 조작 버튼은 화면 크기에 맞춰 유지합니다.

## 검수와 남은 범위

연결 브라우저 도구가 Windows 플랫폼 디렉터리 오류로 시작되지 않아, 같은 Windows PC의 Chrome을 별도의 임시 세션으로 실행해 공개 게임을 확인했습니다. 사용자의 개인 브라우저 프로필·로그인은 사용하지 않았습니다. 실제 시작·플레이·HUD·종료 화면과 390×844 모바일 구성을 캡처했습니다. 종료 화면은 정상 키 입력으로 `gameOver` 상태에 도달한 결과입니다. 성공 클리어 화면은 소스를 확인했으며 실제 완주 캡처는 없습니다.

새 미리보기는 1440×1100, 390×844, 844×390에서 검수했습니다. 에셋 로딩 및 JS 오류 0건, 수집 카운터 08→09, 일시정지/재개, 화면 전환, 가로 넘침 없음 확인. 모바일 버튼은 최소 44×44 CSS px입니다. 알파가 필요한 PNG의 바깥 테두리에 alpha > 16 픽셀이 없고, 실제 체커보드 및 밝고 어두운 배경에서 픽셀을 검사했습니다.

현재 6포즈는 대표 장면 및 동작 전환용 키포즈입니다. 완성된 8~12프레임 달리기 사이클, 피격·벽타기·웅크리기, 적 애니메이션, 9-slice 지형 완전 연결, 모든 레벨 및 실기기 성능 검증은 후속 범위입니다. 상용 플랫폼 게임 전체 수준의 완성도를 보증하는 패키지는 아닙니다.

제작에는 내장 이미지 생성 도구를 사용했습니다. 이 세션이 GPT 아스트라로 실행됐는지 및 이미지 생성 내부 모델명은 확인되지 않았습니다.
